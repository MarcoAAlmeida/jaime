# Mini-notation

Strudel uses a compact language for writing rhythmic patterns.

## Example

Before diving deeper, here is a flavour of how it looks:

<MiniRepl

## Sequences

A space-separated list of steps plays one per cycle-step.

```
s("bd sd hh")
```
