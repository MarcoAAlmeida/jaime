# Effects

Effects are methods that shape each event. Because they take patterns as
arguments, an effect can change over time on its own.

## Filters

- `.lpf(hz)` — low-pass; `.hpf(hz)` — high-pass. `.lpq(n)` sets
  resonance.
- Sweep one with a signal (see below):

  ```strudel
  note("c2").s("sawtooth").lpf(sine.range(200, 2000).slow(4)).lpq(10)
  ```

## Time and space

- `.room(n)` — reverb send (`0`–`1`).
- `.delay(n)` — echo; `.delaytime(s)` and `.delayfeedback(n)` tune it.
- `.speed(n)` — playback rate of a sample (also transposes it).
  Negative values play it backwards.

```strudel
s("hh*8").speed(2).room(0.4).delay(0.3)
```

## Envelope

Every voice has an amplitude envelope: `.attack(s)`, `.decay(s)`,
`.sustain(level)`, `.release(s)`. Short attack + zero sustain = a pluck;
long attack + long release = a pad:

```strudel
note("<c3 g3>").s("sawtooth").attack(1).release(3).gain(0.4).room(0.8)
```

## Signals

`sine`, `saw`, `tri`, `square`, `perlin`, `rand`, and `irand(n)` are
continuous (or random) signals you can feed into any numeric argument.
`.range(lo, hi)` rescales them, `.slow(n)` / `.fast(n)` set their rate,
`.segment(n)` samples them into `n` discrete steps.

```strudel
s("bd*4, hh*8").gain(perlin.range(0.4, 1).fast(2))
```

## Structure

- `.rev()` — reverse the cycle.
- `.fast(n)` / `.slow(n)` — compress or stretch time.
- `.every(n, f)` — apply `f` once every `n` cycles.
- `.sometimesBy(p, f)` — apply `f` to a random `p` fraction of events.
- `.off(t, f)` — layer a copy shifted by `t`, with `f` applied.

```strudel
n("0 2 4").scale("C:major").s("triangle").off(1/8, add(n(7))).every(4, rev)
```
