# Strudel in jaime

Both JAM and the Composition Room run Strudel in your browser — no
server-side audio. The engine is the same one [strudel.cc](https://strudel.cc)
uses: `@strudel/core`, `@strudel/mini`, `@strudel/tonal`,
`@strudel/webaudio`, and `@strudel/draw`, driven through the same
`StrudelMirror` editor. Patterns from strudel.cc run unchanged.

## What you get

- The full pattern language and [mini-notation](/docs/strudel/mini-notation).
- All the synth voices and the **full default sample map** — not just
  `dirt-samples`, but the drum-machine, piano, VCSL and other banks
  strudel.cc loads. See [Sounds](/docs/strudel/sounds).
- `.scale()`, `.voicing()`, chord and note names (`@strudel/tonal`).
- The core transforms (`fast`, `rev`, `every`, `sometimesBy`, `off`, …),
  signals, and the whole [effects](/docs/strudel/effects) chain.
- **`$:` documents** — define several labelled patterns in one editor
  and they play together. Prefix a label with `_` (`$_drums:`) to mute
  it.
- **Mini-notation highlighting** — the token being triggered lights up
  in time with the audio.

## What jaime doesn't do (yet)

- **Pattern-driven visuals** — `.punchcard()`, `.pianoroll()` and
  friends evaluate without error but don't draw anything yet.
- **Hydra** — the WebGL video-synthesis system (`initHydra()`, `H()`)
  is its own language and isn't wired in.
- **MIDI / OSC** — no `.midi()` output or external I/O.
- **Loading your own sample banks** — `samples('github:…')` from inside
  a tool isn't supported; you get the default map.

## Tempo

A JAM room's transport aligns every track's playback to a shared cycle
boundary so the parts lock together — change tempo from the transport
bar. (A per-track `setcps` still takes effect for that track, so leave
it out unless you mean to run that part at its own rate.)

## Starting points

The [pattern library](/app/patterns) is a catalog of Strudel snippets
that all run on this engine — every one has a **Preview** button and a
**Load into JAM** button.
