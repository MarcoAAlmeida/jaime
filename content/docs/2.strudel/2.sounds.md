# Sounds

A pattern's events need a voice. The two starting points are `s()` (a
sample or synth by name) and `note()` / `n()` (pitched material).

## Samples

`s("name")` triggers a sample. jaime loads the same default sample map
strudel.cc bakes — the [`tidalcycles/dirt-samples`](https://github.com/tidalcycles/dirt-samples)
bank (`bd`, `sd`, `hh`, `cp`, `oh`, `amen`, …) plus drum machines,
piano, and the VCSL instrument set, all fetched lazily:

```strudel
s("bd sd, hh*8, ~ cp")
```

A name can hold several variants. Pick one with `:` or the `n` control:

```strudel
s("hh:0 hh:2 hh:4 hh:6")
```

`.chop(n)` cuts a sample into `n` pieces played in order — the classic
breakbeat move:

```strudel
s("amen").chop(8).speed("1 2 1 -1")
```

## Synths

`note()` with `s()` set to an oscillator plays a pitched synth voice —
`sine`, `sawtooth`, `square`, `triangle`, and the rest of Strudel's
synth engine (FM, ZZFX, `.vib()`, `.fm()` …):

```strudel
note("c3 e3 g3 c4").s("sawtooth")
```

`note()` takes note names (`c3`, `fs4`, `bb2`) or MIDI numbers. `n()`
takes scale degrees and needs a scale:

```strudel
n("0 2 4 6").scale("C:minor")
```

Scales come from `@strudel/tonal` — so `.scale()`, `.voicing()`, and
chord names (`note("<Cm7 F7>")`) all work.

## Level and space

`.gain()` sets loudness (per event, so it can be a pattern:
`.gain("1 0.7")`). `.pan()` places it left–right (`0`–`1`). More on
shaping sound in [Effects](/docs/strudel/effects).

The [pattern library](/app/patterns) is tagged by voice — `drums`,
`bass`, `synth`, `pad`, `samples` — if you want examples of each.
