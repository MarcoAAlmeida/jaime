# jaime docs

jaime is a hub of small, music-oriented tools. These pages collect
notes, references, and guides for the live-coding languages the tools
speak — starting with [Strudel](/docs/strudel), the pattern language
behind JAM.

Deep-dive content is still being written. This section exists now so
the structure is in place for it.
