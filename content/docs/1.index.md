# jaime docs

jaime is a hangout for developers — a room to chat, live-code, and ask
`@jah`. These pages collect notes, references, and guides for the
live-coding languages the rooms speak, and the data sources their
features are built on — starting
with [ASCII Art](/docs/ascii-art), the source behind the Composition
Room's ASCII panel.

Deep-dive content is still being written. This section exists now so
the structure is in place for it.
