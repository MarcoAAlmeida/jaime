# Strudel

[Strudel](https://strudel.cc) is a live-coding pattern language — a
JavaScript port of [TidalCycles](https://tidalcycles.org). You describe
music as *patterns* — repeating structures in time — and the code is
re-evaluated live while it plays. JAM uses Strudel as the language each
player types into their track, and the [pattern library](/app/patterns)
is a catalog of Strudel snippets to start from.

## The shape of a pattern

Everything is built from a **cycle** — one loop of musical time, one bar
by default. A pattern says what happens across a cycle:

```strudel
s("bd sd bd sd")
```

Four sounds, evenly spaced, forever. The tempo (how long a cycle lasts)
is set globally — in JAM, by the shared transport clock, so every
player's cycles line up.

Patterns are values you transform by chaining methods:

```strudel
s("bd sd bd sd").fast(2).rev().gain(0.8)
```

Each call returns a new pattern, so they compose without touching what
came before.
