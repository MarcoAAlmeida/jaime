# Strudel

[Strudel](https://strudel.cc) is a live-coding pattern language — a
JavaScript port of TidalCycles. JAM uses it as the language each player
types into their track.

A proper reference — pattern syntax, the mini-notation, sound sources,
effects, and the subset JAM currently supports — will be written here
in a later phase. For now, the canonical documentation lives at
[strudel.cc/learn](https://strudel.cc/learn).
