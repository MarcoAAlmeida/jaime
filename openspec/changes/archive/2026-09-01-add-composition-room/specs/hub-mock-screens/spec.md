## REMOVED Requirements

### Requirement: Composition Room Mock Shows Its Core Elements
**Reason**: The Composition Room is a real tool now — see the new
`composition-room` capability. `/app/composition` is a working
collaborative editor with real presence, roles, synced playback, and
chat, not a static stand-in.
**Migration**: Replaced by the `composition-room` capability's
requirements (collaborative editing, editor/viewer roles, presence and
cursors, room chat). The `hub-mock-screens` capability now has no
remaining requirements and its spec is retired.
