## REMOVED Requirements

### Requirement: Pattern Library Mock Shows Example Patterns
**Reason**: The Pattern library is now a real feature backed by a
durable catalog — see the new `pattern-library` capability. `/app/patterns`
is no longer a mock.
**Migration**: Replaced by `pattern-library`'s browsing, search, and
attribution requirements, served from the real pattern-library API
instead of a static in-page array.
